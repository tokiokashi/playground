量子自殺マインスイーパー

この盤には最初から決まった地雷の配置が無い。手がかりと矛盾しない全ての配置（世界）が重なっていて、マスを踏むと、そこに地雷があった世界は消え、あんたは生き残った世界へ進む。世界を1つ（Ω = 1）に絞ればクリア。

残っている世界 Ω
命で払った L
観測で得た I
この世界線のあんたが残る確率 2−L

ルールと数え方

盤は地雷の配置を持っていない。開いたマスの手がかりと地雷の総数に矛盾しない配置を全て数え、その数を Ω とする。マスの地雷確率 p は、Ω 個の世界のうち、そのマスに地雷がある世界の割合。

  • p のマスを踏むと、地雷があった世界が消える。生き残る世界は Ω(1−p) 個になり、そのぶんを −log₂(1−p) ビットとして L に足す。p = 0 のマスならコストは 0。
  • 開いたマスの数字は、生き残った世界の中から重みどおりに引かれる。開ける前は本当に決まっていない。数字で世界が絞られたぶんを I に足す。
  • 最初の世界の数は Ω₀ = C(マス数, 地雷数)。常に L + I + log₂Ω = log₂Ω₀ が成り立つ。
  • 評価のモードは2つある。
    • 安全第一: 地雷の可能性をできるだけ避ける推理を評価する。L を手ごとに分け、安全なマスが残っていたのに危ないマスを踏んだ分（推理ミス）と、賭けるしかない時に一番安全なマスより危ないマスを選んだ分（賭けの損）の合計でランクが決まる。どちらも踏んだ時点の盤面だけで決まるので、後から引かれた数字の運に左右されない。
    • 最小コスト: 払った L の合計を、必要だった情報 log₂Ω₀ に対する割合で評価する。安全なマスを残したまま賭けてもよい。安全なマスの数字は開けるまで決まっていないので、残りの世界をちょうど半分に割れる場面までとっておくと、得られる情報が大きくなる。そのため、先に賭けた方が L の合計が小さくなる局面がある。最善手は計算できないので、評価は数字の運も含む。
  • 2−L は、地雷の配置が最初から1つ決まっていたとしたら、あんたがここまで生き残れた確率と同じ値になる。
  • 精密な 0 の周りは自動で開く。それ以外の安全なマスは自分で推理して開ける。全ての世界で地雷のマス（p = 1）を踏むと、どの世界にもあんたは残らない。
  • 開いた手がかりのマスを押すと、その手がかりと周りの旗だけで残りが安全と決まる時に、周りをまとめて開ける。旗が世界と合っていなければ、開けたマスの確率どおりにコストを払う。
  • 安全第一のモードでは、「0% を自動で開ける」を有効にすると、全ての世界で安全なマスをコストなしで自動で開ける。
  • 旗はメモで、世界の数には影響しない。長押し、右クリック、「旗を置く」で置ける。

「曖昧な手がかり」が有効だと（最初から有効）、マスごとに検出器の種類が決まり、右上の印で見分けられる。

  • 印なし: 精密。周囲の地雷の数をそのまま出す。
  • ≈ 幅: 0-1 / 2-3 / 4-5 / 6-7 / 8 のどれかを出す。
  • | 二重: 0|2 / 1|3 / 4|6 / 5|7 / 8 のどれかを出す。
  • ◐ 偶奇: 偶か奇だけを出す。

同じ表示になる地雷数の組は配置によらず決まっているので、どの世界も同じ重みのまま数えられる。
