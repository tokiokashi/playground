Belousov–Zhabotinsky reaction

BZ反応はなぜ振動するのか

かき混ぜたビーカーの液が赤と青を行き来し、かき混ぜないシャーレには波が広がる。仕組みは水飲み鳥と同じで、「ゆっくり溜まる → しきい値で一気に変わる → リセット」の繰り返しです。

振動に必要な3つの条件

平衡から遠い燃料（臭素酸と有機酸）がたっぷりあり、坂を下りきるまで時間がかかる
自己触媒亜臭素酸が自分自身を増やす。増え始めると爆発的に増える
遅れて作られるブレーキ役増加を止める臭化物イオンが、少し遅れて作られる

1周の流れ

①ゆっくり

ブレーキが少しずつ減る

臭化物イオンが臭素酸に消費されていく。臭化物イオンがある間は、自己触媒の反応は抑えられている。

液は赤

水飲み鳥：頭が冷えて、胴体の液が少しずつ首を上がる

②一瞬

しきい値を切って爆発

臭化物イオンが一定量を切った瞬間、亜臭素酸が爆発的に自己増殖し、触媒の金属イオンが酸化される。

液が青に変わる

水飲み鳥：重心が前に越えた瞬間、カクンと倒れる

③速い

リセット

酸化された触媒が有機酸と反応して元に戻る。このとき臭化物イオンが放出され、ブレーキが掛かり直す。

液が赤に戻っていく

水飲み鳥：倒れると中の気体が通じ、液が胴体に戻って起き上がる

③のあと①に戻る。燃料が尽きるまで繰り返す（水飲み鳥なら、頭の水が乾くまで）。

反応式（FKN機構）

硫酸で酸性にした水に、臭素酸ナトリウム（燃料）、マロン酸（有機酸の燃料）、触媒のセリウムイオンを溶かす。色を見やすくする時は、触媒の代わりにフェロイン（鉄の錯体）を使う。主役は亜臭素酸 HBrO2 で、①②③はそれぞれ下の反応のまとまりに当たる。

①過程A：臭化物イオンが消費される

BrO3− + Br− + 2H+ → HBrO2 + HOBr燃料が臭化物イオンを消費する
HBrO2 + Br− + H+ → 2HOBrできた亜臭素酸も、臭化物イオンに消費されて増えられない
HOBr + Br− + H+ → Br2 + H2O
Br2 + CH2(COOH)2 → BrCH(COOH)2 + Br− + H+臭素がマロン酸に付き、ブロモマロン酸ができる

②過程B：亜臭素酸の自己触媒

BrO3− + HBrO2 + H+ → 2BrO2• + H2O亜臭素酸1個からラジカルが2個
BrO2• + Ce3+ + H+ → HBrO2 + Ce4+ラジカル1個が亜臭素酸1個に戻り、触媒が酸化される（2回起きる）
BrO3− + HBrO2 + 2Ce3+ + 3H+ → 2HBrO2 + 2Ce4+ + H2O合計すると、亜臭素酸が1個から2個になる。これが自己触媒
2HBrO2 → BrO3− + HOBr + H+増えすぎると亜臭素酸どうしで分解する。爆発の上限を決める
Fe(phen)32+（赤） → Fe(phen)33+（青）フェロインを使った時の色の変化

③過程C：触媒が戻り、臭化物イオンが放出される

4Ce4+ + BrCH(COOH)2 + 2H2O → 4Ce3+ + Br− + HCOOH + 2CO2 + 5H+①で作ったブロモマロン酸から臭化物イオンが戻る。泡（CO2）が出るのはこの反応

しきい値の正体：亜臭素酸の取り合い

亜臭素酸 HBrO2 は、①の2つ目の反応（臭化物イオンに消費される）と、②の1つ目の反応（燃料と反応して増える）の両方に使われる。どちらが速いかは次の比べっこで決まる。

k2[Br−] と k5[BrO3−]

臭化物イオンが多い間は左が勝って、亜臭素酸は増えられない。臭化物イオンが [Br−]crit = (k5/k2)[BrO3−] を下回った瞬間に右が勝って、②の爆発が始まる。FKN の見積もりでは、この境目は臭素酸の濃度の数十万分の1程度しかない。

5つにまとめた形（オレゴネーター）

A + Y → X + P①
X + Y → 2P①（亜臭素酸が消費される）
A + X → 2X + 2Z②（自己触媒）
2X → A + P②（上限）
B + Z → (f/2) Y③（ブレーキの再生）

X = HBrO2、Y = Br−、Z = Ce4+、A = BrO3−、B = 有機酸、P = HOBr などの生成物。次のグラフはこの5つの反応を計算したもの。

かき混ぜたビーカーの中で起きていること

かき混ぜないと波になる

らせんができる理由

a. 途中で切れた波。上へ進み、すぐ後ろ（薄い帯）は不応期で発火できない。

b. 端の先は休んでいる液なので、波は横にも広がる。真後ろの不応期には入れないので、端は不応期の帯のふちに沿って巻き込む。

c. 端が1周して戻る頃には、最初に通った場所の不応期が明けている。端はぐるぐる回り続け、外側の波は外へ進み続けるので、らせんになる。

  1. 同心円の輪には端がない。だから中心から外へ広がるだけで、回転は起きない。
  2. 波が途中で切れると端ができる。端は「前には進めるが、真後ろには戻れない」ので、不応期の帯のふちを回るように曲がっていく。
  3. きつく曲がった波は遅い。曲がりの内側から外側へ物質が拡散で逃げて、隣を発火させる力が弱まるからだ。端は一番きつく曲がっているので一番遅く、外側ほど速く進む。この速さの差で、波は中心に巻き付くように伸びていく。
  4. 実際の液では、泡やほこりに当たったり、液を少し揺らしたりすると波が切れて、らせんが生まれる。心臓の中で同じことが起きた状態が、心室細動などの不整脈だと考えられている。

振り子との違い

振り子が行き過ぎるのは、動く物体に勢い（慣性）が残るから。化学反応の速さは「今の濃度」だけで決まり、慣性がないので、平衡のすぐ近くでは行ったり来たりせずに止まる。BZ反応は慣性の代わりに燃料の流れで揺れている。だから振り子のように揺れが減衰していくのではなく、燃料がある限り同じ振幅で続く（リミットサイクル）。
