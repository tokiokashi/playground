フォトニック結晶 H3 共振器の 2D FDTD

三角格子エアホールの Hn 共振器を、スラブの実効屈折率で 2D に落として TE 偏光で解く。外周の穴を円形に寄せる変形率を変えて、共振周波数・面内 Q・垂直放射の目安がどう変わるかを見る。

色: Hz（赤 正／青 負、毎フレーム最大値で正規化）。灰色が誘電体、黒が空気穴、縁の暗い帯が PML。
パラメータを決めて「① スペクトル」を押す。

① 共振スペクトル（プローブ点の |Hz(f)|、対数）

横軸は規格化周波数 a/λ、上の目盛りは波長 nm（格子定数 a から換算）。ピークをタップするか下のボタンでモードを選ぶ。

② 選んだモード

減衰中の Hz をモード周波数で時間 DFT した複素振幅 F から描く。絶対値は |F|。正負ありは、実部の二乗和が最大になる共通の位相 φ を選んだ Re[F e−iφ] で、定在波が一番大きく振れた瞬間の Hz に当たる。黒い輪郭が空気穴。
未測定
モード場の空間フーリエ |H̃z(k)|²（対数）。白い円が光円錐 |k| = ncladω/c。中の成分がスラブの上下（クラッド側）に漏れる。

③ 変形率スイープ

左: 面内 Q（2D、対数軸）。右: 光円錐内の成分比 η（小さいほど垂直放射が少ない）。各点で ① と ② を自動で回し、直前の点に近い周波数のピークのうち、最初の点と同じ方位角次数 m のモードを追う（近い順に3つまで試す）。

④ W1 導波路の分散曲線

導波路の方向（x）に1周期ぶんの単位セルを取り、x に Bloch の周期境界 H(x + a) = H(x) eika、y に PML を置いて、k ごとに広帯域パルスのスペクトルからモードの周波数を拾う。r/a・屈折率・分解能は構造パネルの値を使う。橙が Hz が導波路の中心線に対して偶のモード、青が奇のモードで、色が濃いほど導波路に局在している（薄い点は結晶全体に広がるバルクのモード）。破線は ② で測ったモードの周波数、灰色の線はクラッドの光円錐 a/λ = k/(2π nclad/a)。破線と濃い点が交わる所に導波モードがあれば、共振器は導波路と結合できる。

⑤ 共振器の半径スイープ（波長多重）

導波路などほかの構造はそのままにして、外周の補正を「変形率 100%・半径を指定」にした共振器の半径 R だけを振る。各 R で「WGM を探す」と同じ手順で基本 WGM を探し、波長と負荷 Q（QL）を測る。探す範囲は、最初の点だけ「探す範囲」の設定を使い、2点目は直前の点の周波数の ±0.015、3点目からは直前の2点の周波数を R について直線で延ばした値の ±0.008（a/λ）に自動で絞る。下に各 R のモード像を並べる（表示は ② の |Hz|・符号付きの切り替えに従う）。左: 波長、右: QL（橙、対数軸）と結合効率 ηc（青、0〜1）。導波路ありの時は、最初に中央の R で導波路なしの Q0 を1回だけ測り、導波路への結合だけの Q を 1/Qwg = 1/QL − 1/Q0 で出す。ηc = 1 − Q/Qs は、実際の素子の共振器単体の Q を Qs とみなして、Qwg と Qs から求める（2D の Q0 は垂直放射を含まないので使わない）。Q0 が下限しか出ない時は、Qwg と ηc を幅で表に出し、図の ηc は Qwg = QL とした上限を描く。近藤研の CirD の解析（Xiong et al., Photonics 2019）は、3D 計算で Qs > 5000 を得ていて、ηc ≈ 0.6 を適当な値としている。⑤ を回すと、構造パネルの補正の設定と ② の表示は最後の R のものになる。④ のバンドの端より長波長側（低周波側）では、導波路の基本モードが無いので結合が弱くなる。

⑥ サブ共振器の両端シフトのスイープ（出力の方向）

導波路とサブ共振器を置いた構造で、Ln の両端の穴のシフトだけを振る。シフトで Ln の共振周波数が動き、WGM との離調が変わる。各点で「WGM を探す」と同じ手順で WGM を探し、波長、負荷 Q（QL）、導波路の左右へ出ていったエネルギーの比を測る。探す範囲は、最初の点だけ「探す範囲」の設定を使い、2点目からは直前の点の周波数の ±0.01（a/λ）に絞る。左: 波長、右: QL（橙、対数軸）と、右へ出た割合（0〜1、0.5 で左右対称。青が同相励振、紫が逆相励振）。下に各点のモード像を並べる。WGM と Ln が強く結合すると、2つが混ざったモードになって、腹の数で WGM を判定できなくなることがある。

モデルと限界

  • 2D TE（Ex, Ey, Hz）の Yee 格子。外周は誘電体（穴なしスラブ）を挟んで分割場 PML で吸収する。誘電率は 4×4 のサブサンプルで平均する。
  • 面内 Q は、共振器内のエネルギー U の指数減衰 U ∝ exp(−ωt/Q) の傾きから求める。2D なので面内の結晶層を抜ける漏れだけを見ている。
  • 実際のスラブで支配的な垂直放射は 2D では出てこない。代わりに、モード場の空間フーリエ成分のうちクラッドの光円錐 |k| < ncladω/c の内側にある割合 η を目安として出す（Vučković らの光円錐解析の簡略版。Hz だけを使う）。η は相対比較用で、Q⊥ の絶対値ではない。
  • 屈折率の既定値 3.4 は GaAs（ε = 11.6）そのもので、CirD の学位論文が 2D の禁止帯の計算に使った値に合わせてある。空気クラッドの薄いスラブ（厚さ 0.5a 前後）を近似するなら TE 基本モードの実効屈折率 2.8〜3.0 くらいに下げる。下げると禁止帯とモードは高周波側（短波長側）へ動く。

構造

サブ共振器 Ln は、共振器と導波路の間の列から、横位置 x に近い穴を n 個抜いた線欠陥。「置く列」は共振器側から数えた列の番号で、共振器との間の列数より大きい値は一番導波路側の列になる。x = 0 は共振器の中心の真上で、0 からずらすと共振器と導波路の配置が左右非対称になる。穴の横位置は、共振器側から奇数番目の列（H3 なら 1 列目）では整数、偶数番目の列では半整数（a 単位）なので、左右対称に置けるのは、奇数番目の列では n が奇数で x = 0、偶数番目の列では n が偶数で x = 0 の時だけ。両端の穴は外向きにシフトして、Ln の共振周波数を WGM に合わせ込む。導波路があるときだけ使う。サブ共振器を置いて「WGM を探す」か ⑥ を回すと、見つけた WGM とは別に、励振点とその鏡像（x = 0 について折り返した点）を同相と逆相で励振して、それぞれスペクトルから WGM を探し直す。左右対称な構造なら、同相は鏡映に対して偶、逆相は奇のモードだけを励振する。WGM は偶と奇の2つの定在波の組で、共振器の六角形の対称性やサブ共振器で別々の周波数に割れるので、それぞれを自分の周波数で測るため。非対称な構造では偶・奇は近似になる。既定の構造（H3、変形率 100%）では、外周に並ぶ 18 個の穴が m = ±9 を強く結び付けるので、偶（穴が定在波の節に来る）と奇は 2D で約 40 nm 離れる。逆相で探す範囲は見つけた WGM の ±0.006（a/λ）なので奇の相方はその外にあり、範囲内の逆相のピークは m = 9 でないので、逆相の欄は「WGM が見つからない」になる。各モードで、導波路の左右の端（PML の手前）のポインティングベクトルを導波路の断面にわたって積分し、減衰の観測区間に左右へ出ていったエネルギーの比を出す。左右対称な構造なら、どちらの励振でも 50 : 50 になる。あわせて、モード場を外周に沿って角度でフーリエ分解し、e∓imφ の成分の比から共振器の中の反時計回りと時計回りの割合を出す（② には1点励振の場合の値も出す）。
W1 導波路は、共振器の上側で穴の横一列を抜いた線欠陥。両端は PML まで伸びていて、導波路に移った光はそこで吸収される。導波路ありで測る Q は導波路への結合を含む Q（負荷 Q）になる。導波路なしの Q を Q0、ありを QL とすると、導波路への結合だけの Q は 1/Qwg = 1/QL − 1/Q0。「両側の列」は導波路のすぐ両側の2列で、シフトは導波路から遠ざける向きを正とする（単位 a）。正で導波路が広がってバンドが下がり、負で狭まって上がる。穴を大きくしてもバンドは上がる。この2つは ④ のバンド計算にも同じように入る。既定の −0.165a は、偶モードのバンドの端（k = 0.5）を WGM の少し下まで上げて、遅い光の領域で WGM と交差させる設定。この 2D モデルでは、間の列数 1 で QL は 3,000〜4,000 程度になる（分解能と観測時間で変わる）。

外周の円形補正

穴の位置 ρ を半径方向に ρ + 変形率 ×（R − ρ）へ動かす。0 で元の六角形、1 で半径 R の円周上にそろう。「補正する列」は共振器のすぐ外の列から数えた列数で、2列目以降も同じ種類の円（平均半径・内接円・外接円はその列のもの、指定時は R + 列の差×√3/2）へ寄せる。Hn は一辺 n 個の穴を抜いた六角形。大阪大学 近藤研の CirD レーザーは H3 の外周 18 個を半径 R ≈ 2.75a の円に移した modified H3 で、ここでは変形率 100%・平均半径（2.76a）がほぼそれに当たる。

計算

1点の時は励振とプローブを同じ点に置く。WGM は外周に沿った腹を持つので、外周の穴の少し内側（H3 なら半径 2a 前後）が目安。角度 0° は外周の角の穴の方向で、WGM の対称・反対称の両方を拾えるように少しずらしてある。
「WGM を探す」は、この範囲（a/λ）のピークだけを調べて、腹の数が外周の穴の数（Hn なら 6n 個）と同じモードのうち一番低い周波数のもの（径方向の基本モード）を選び、② まで回す。スペクトル上では範囲を薄い帯で示す。
サブ共振器を置いた時の ②（「WGM を探す」と ⑥ を含む）は、減衰の観測時間をこの値以上にする。導波路の左右への出力は観測区間全体の時間 DFT で WGM の周波数の成分だけを取り出して比べるが、WGM の 2 nm 前後の近くには導波路に強く出る別のモードがあり、観測時間が短いと周波数で分けられずに左右比が混ざる。3000 a/c で周波数の分解能は約 0.0007（a/λ、1450 nm で約 4 nm）。
