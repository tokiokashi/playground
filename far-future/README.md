# 遠未来タイムマシン

1万年後から 10<sup>10<sup>10<sup>56</sup></sup></sup></sup> 年後まで、遠い未来に起きると予想されている出来事を、1件ずつ想像図つきで見て回る。

- ▶ で次の出来事へ跳ぶ。下の目盛りをなぞると、途中の時間も含めて行き来できる
- 同じ時刻に複数の出来事がある時は、右(スマホでは下)の一覧から選ぶと絵が切り替わる
- 分野のボタンで、表示する出来事を絞り込める

## 出典とライセンス

- 出来事の一覧と内容: Wikipedia 日本語版「[遠い未来のタイムライン](https://ja.wikipedia.org/wiki/%E9%81%A0%E3%81%84%E6%9C%AA%E6%9D%A5%E3%81%AE%E3%82%BF%E3%82%A4%E3%83%A0%E3%83%A9%E3%82%A4%E3%83%B3)」(CC BY-SA 4.0)。文章は要約し直し、誤訳とみられる箇所は英語版「[Timeline of the far future](https://en.wikipedia.org/wiki/Timeline_of_the_far_future)」(CC BY-SA 4.0)で確かめて直した。このため `events.js` の文章は **CC BY-SA 4.0** で提供する(リポジトリ全体の MIT とは別)
- 陸地の輪郭(`geo.js`): [Natural Earth](https://www.naturalearthdata.com/) 1:110m(パブリックドメイン)を [world-atlas](https://github.com/topojson/world-atlas)(ISC)経由で取得し、国ごとの輪郭をプレート単位にまとめて点を間引いたもの
- それ以外のコードと絵: MIT(リポジトリの LICENSE)

## 絵の作り方

画像ファイルは使っていない。すべて Canvas 2D で描いている。

- 大陸移動(`plates.js`): 現在の陸地をプレートごとに球面上で回転させる。2億5000万年後の配置は Scotese のパンゲア・プロキシマ予想(アフリカが北上して地中海が閉じ、北米がアフリカへ、南米がアフリカ南端を回り込み、南極がマダガスカル・豪州とぶつかってインド洋の名残が内海になる)に目で合わせた近似で、計算による再現ではない
- 太陽の半径(`space.js` の `SUN_R`): 主系列の終わりから赤色巨星の先端(約256倍)、白色矮星までを折れ線で近似した
- 天の川銀河とアンドロメダ銀河の合体は、NASA/ESA のハッブルの想像図シリーズの記述(合体後は巨大な楕円銀河)を参考にした
- 縮退の時代・ブラックホールの時代・暗黒の時代の区分は Adams & Laughlin『宇宙のエンドゲーム(The Five Ages of the Universe)』に合わせた
- 大きさ・明るさ・色は見やすさのために誇張している。宇宙背景放射やホーキング放射のように目に見えないものにも色を付けている
